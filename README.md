## 三、安装与首次运行

### 3.1 安装版

1. 双击 `Unknow Setup 0.1.1.exe`；
2. 按安装向导提示选择安装目录；
3. 完成后从开始菜单或桌面快捷方式启动程序。

### 3.2 便携版

直接双击 `Unknow 0.1.1.exe` 即可运行，无需安装。可将该文件复制到 U 盘或任意目录使用。

### 3.3 首次运行的系统提示（重要）

本程序**未做代码签名**，首次运行时可能出现以下系统提示，属正常现象：

- **Windows SmartScreen 拦截**：弹出「Windows 已保护你的电脑」提示时，点击 **「更多信息」**，再点击 **「仍要运行」** 即可继续。
- **杀毒软件误报**：部分杀毒软件可能对未签名程序给出风险提示或拦截，可自行将该文件添加至信任列表。

## 四、功能概览

- **对话式 AI 助手**：以多轮对话方式完成问答与任务。
- **模型服务接入**：支持接入遵循 OpenAI 兼容协议的模型 API。
- **网页版 AI**：在设置中登录对应网站后，由本地程序驱动网页端完成对话；回复以 Markdown 呈现，支持代码高亮、表格、公式。
- **文件与项目目录操作**：可读取、搜索、编辑、生成本机文件及项目目录内容。
- **本机命令执行与预览**：可执行本机命令并预览结果。
- **任务与计划**：支持任务与计划类工作流。
- **扩展能力**：支持 MCP 与 Skill 扩展。
- **桌面悬浮球与全局快捷键**：悬浮球常驻桌面，默认快捷键 `Alt+Shift+S` 唤醒输入框。

## 五、基本使用步骤

1. **启动程序**（安装版从快捷方式启动，便携版双击 exe）。
2. **配置模型服务**：打开设置，任选其一——
   - 填入模型服务信息：**API 地址**、**密钥**、**模型名**；
   - 或登录网页版 AI（在设置中完成对应站点登录）。
3. **开始对话**：在主输入框用自然语言描述你的需求即可。

> 输入框支持附带**本地文件**或**整个文件夹**作为上下文，便于让 AI 直接读取相关内容后作答。

## 六、数据与隐私

- 所有对话记录、配置与日志均保存在**本机用户目录**，不会上传至作者服务器。
- 使用 **API 模式**时，对话数据会直接发送至你自行配置的模型服务商。
- 使用**网页版 AI** 时，对话数据会发送至对应的网站。

> 数据去向取决于你选择的服务方式，作者不参与、不中转、不留存任何对话内容。

## 七、常见问题（FAQ）

### Q1：运行时报「Windows 已保护你的电脑」怎么办？

这是 Windows SmartScreen 对未签名程序的常规拦截提示。点击 **「更多信息」** → **「仍要运行」** 即可正常启动。

### Q2：提示「网页版 AI 未就绪」怎么办？

说明该网页版 AI 站点尚未登录。请先进入 **设置**，完成对应网站的登录，再返回使用。

### Q3：模型回复报错怎么办？

请先检查设置中的 **API 地址** 与 **密钥** 是否正确、是否已填写对应**模型名**，以及所填模型服务是否可用。

### Q4：日志在哪里？

日志位于**程序数据目录**下的 `logs` 文件夹中：

```text
<程序数据目录>\logs\
```
