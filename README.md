
# Unknow 使用说明书

Unknow 是一款面向 Windows 的桌面 AI 助手。**安装包与便携版请在右侧 Releases 页面下载**，本仓库仅提供使用说明，不包含源代码。

`平台 Windows 10 / 11 64 位` &nbsp;|&nbsp; `作者 None-wu`

## 一、本目录内容

| 文件 | 类型 | 说明 |
|---|---|---|
| `Unknow Setup <版本>.exe` | NSIS 安装版 | 按向导安装，可选安装目录，自动生成开始菜单与桌面快捷方式，支持卸载 |
| `Unknow <版本>.exe` | 便携版 | 免安装，双击即用，可放 U 盘随身携带 |

两个文件内容等价，任选其一。

## 三、安装与首次运行

### 3.1 安装版

1. 双击 `Unknow Setup <版本>.exe`；
2. 按安装向导提示选择安装目录；
3. 完成后从开始菜单或桌面快捷方式启动程序。

### 3.2 便携版

双击 `Unknow <版本>.exe` 即可运行，无需安装。可将该文件复制到 U 盘或任意目录使用。

### 3.3 首次运行的系统提示（重要）

本程序**未做代码签名**，首次运行时可能出现以下系统提示，属正常现象：

- **Windows SmartScreen 拦截**：弹出「Windows 已保护你的电脑」提示时，点击 **「更多信息」**，再点击 **「仍要运行」** 即可继续。
- **杀毒软件误报**：部分杀毒软件可能对未签名程序给出风险提示或拦截，可自行将该文件添加至信任列表。

## 四、功能概览

- **对话式 AI 助手**：以多轮对话方式完成问答与任务，单轮对话不限制工具调用轮次。
- **模型服务接入**：支持接入遵循 OpenAI 兼容协议的模型 API。
- **网页版 AI**：内置多个常用站点，也支持自行添加/删除站点；登录后由本地程序驱动网页端完成对话，回复实时流式显示，以 Markdown 呈现，支持代码高亮、表格、公式，网页端生成的图片与代码文件可回传到本地界面。
- **任务中心**：只给「目标 + 约束」，程序自动拆解成执行链路、并行推进；执行过程中可随时插话、改目标、纠偏，结束后输出一份任务报告。
- **划词翻译（内置引擎，不消耗 token）**：选中任意文字即可唤出气泡翻译，默认走公开翻译接口，毫秒级返回；应用内（主界面、回答气泡、输入框、预览面板）与外部程序（浏览器、Word 等）都支持。
- **截屏问 AI**：快捷键框选屏幕区域，直接把截图作为问题发出去；多屏时按鼠标所在屏幕截取。
- **文件与项目目录操作**：可读取、搜索、编辑、生成本机文件及项目目录内容。
- **本机命令执行与预览**：可执行本机命令并预览结果。
- **网络出口**：内置代理内核，客户机零依赖即可访问外网；模型/更新连不上时可在「设置 → 网络出口」一键开启。
- **扩展能力**：支持 MCP、插件（插件随应用内置，开箱可用，不依赖本机其他软件）与 Skill 扩展。
- **桌面悬浮球与全局快捷键**：悬浮球常驻桌面，快捷键可在「设置 → 快捷键」中修改。
- **版本更新检查**：启动后自动检测新版本，也可在「设置 → 关于」手动检查。

### 4.1 默认快捷键

| 功能 | 默认快捷键 |
|---|---|
| 快速提问 | `Alt+Space` |
| 显示/隐藏悬浮球 | `Alt+Shift+A` |
| 划词问 Unknow | `Alt+Shift+S` |
| 截屏问 Unknow | `Alt+Shift+X` |
| 显示主界面 | `Alt+Shift+M` |

> 快捷键均可在「设置 → 快捷键」中修改；升级后自定义设置会随数据目录保留。

## 五、基本使用步骤

1. **启动程序**（安装版从快捷方式启动，便携版双击 exe）。
2. **配置模型服务**：打开设置，任选其一——
   - 填入模型服务信息：**API 地址**、**密钥**、**模型名**；
   - 或登录网页版 AI（在「设置 → 网页版 AI」中完成对应站点登录）。
3. **开始对话**：在主输入框用自然语言描述你的需求即可。

> 输入框支持附带**本地文件**或**整个文件夹**作为上下文，便于让 AI 直接读取相关内容后作答。
>
> 若模型请求一直失败、更新检测也不通，先到「设置 → 网络出口」把出口开关打开再重试。

### 5.1 使用任务中心

任务中心用于「一句话交代目标，程序自己跑完」的场景。

1. 左侧进入 **任务**，填写两项：
   - **任务目标**：期望达成的结果（例：把 E 盘 30 天前的日志归档成 zip 并给出摘要）；
   - **约束**（可选）：边界条件（例：只允许读取 `E:\logs`，禁止联网上传）。
2. 点创建后，任务会先做规划，再按依赖并行执行多个步骤；卡片上可直接看到状态与进度。
3. 点任务卡片进入独立详情页，分五个视图：

| 视图 | 内容 |
|---|---|
| 总览 | 目标、约束、步骤清单与各自状态 |
| 链路 | 步骤之间的依赖关系图 |
| 播报 | 执行过程中的事件流（新发现、失败、纠偏） |
| 会话 | 每一步对应的独立会话，可单独回看轨迹 |
| 报告 | 收尾时汇总的任务报告 |

4. **执行中随时介入**（人在环路）：
   - **提示**：给规划器补一句方向，例如「跳过第 3 步，直接用备份目录」；
   - **插入步骤**：直接加一条要执行的步骤；
   - **纠偏**：中止正在跑的那一步，附上说明后重跑；
   - **改目标**：目标变了就改目标，后续规划按新目标走。

任务状态含义：**运行中 / 已暂停 / 已完成 / 已失败 / 预算耗尽**。「预算耗尽」不是硬性中断，程序会把已有发现总结成报告再收尾。

### 5.2 使用划词翻译

1. 选中任意文字，用快捷键 `Alt+Shift+S` 或点悬浮球发起；
2. 气泡中直接显示译文，并标注实际使用的引擎（默认腾讯交互翻译，失败按 Bing / Google / MyMemory 依次兜底）；
3. 在气泡内可临时切换**译入语言**并重翻；
4. 需要更自然的意译时，点气泡内的 **「AI 翻译」**，此时才调用当前模型，会消耗 token。

应用内（主界面、回答气泡、提问框、预览面板）与外部程序均可划词，中文取词已做适配。

相关默认值在「设置 → 翻译」中调整：内置翻译引擎、默认译入语言、以及「内置翻译失败时自动改用 AI」（默认关闭，避免失败时静默消耗 token）。

### 5.3 使用截屏问 AI

1. 按 `Alt+Shift+X`（或点悬浮球里的截屏）；
2. 鼠标拖拽框选要问的区域，确认后直接带着截图发起提问；
3. 多显示器时默认截取**鼠标所在的那块屏**，可在框选界面切换屏幕。

截图会临时存放在数据目录的 `data\shots` 下，程序自动只保留最近 7 天、最多 300 张，无需手动清理。

## 六、数据与隐私

- 所有对话记录、配置与日志均保存在**本机用户目录**，不会上传至作者服务器。
- 使用 **API 模式**时，对话数据会直接发送至你自行配置的模型服务商。
- 使用**网页版 AI** 时，对话数据会发送至对应的网站。

> 数据去向取决于你选择的服务方式，作者不参与、不中转、不留存任何对话内容。

### 6.1 数据保存在哪里

程序数据统一保存在当前 Windows 用户目录下，不依赖固定盘符，也不读取任何外部位置：

```text
%APPDATA%\Unknow\agent\
├─ data\          会话库 agent.db、设置 prefs.json、截图 shots、网页版 AI 站点配置
├─ attachments\   对话附件
├─ plugins\       自装插件（可选）
├─ skills\        已安装技能包
├─ mcp\           已安装 MCP 服务
└─ logs\          运行日志
```

- **全新安装即为空白**：安装包内不携带任何数据，首次启动时上述目录从零创建，不会从其他地方导入会话、附件或配置。
- 数据只属于当前 Windows 用户；换机迁移时，把 `%APPDATA%\Unknow\agent` 整个目录拷到新机器同位置即可恢复全部会话。
- 如需自定义位置，可用环境变量 `AGENT_ROOT` 指定数据根目录（优先级最高）。
- 卸载后若需彻底清除痕迹，删除 `%APPDATA%\Unknow` 目录即可。

### 6.2 联网行为的两处例外（仅版本与崩溃信息）

除对话本身外，程序只有两项联网行为，均不涉及对话内容：

| 行为 | 何时发生 | 传输内容 |
|---|---|---|
| 版本检测 | 启动后自动进行，失败会自动重试；也可在「设置 → 关于」手动触发 | 仅当前版本号与随机设备标识，用于取回最新版本清单 |
| 崩溃日志上传 | **仅在你点击确认后**发生（程序异常退出后启动时会询问，7 天内最多问一次） | 最近 3 天的运行日志（最多 6 个文件，单文件取尾部 2 MB）与崩溃堆栈，路径中的用户名会被脱敏 |

两项都可在「设置 → 关于」查看与手动操作；拒绝上传不影响任何功能。

> 「不保存划词内容」开关（设置 → 隐私与数据）会在划词提问后抹掉该次提问里保存的选区文本；若你关闭了它，选区会随该轮对话一起留在本地会话库中。

## 七、升级与卸载

- **升级**：程序启动后会自动提示新版本；也可在「设置 → 关于」点击 **「检查更新」**。安装版直接运行新安装包覆盖即可，便携版替换 exe 文件。
- **数据保留**：覆盖升级不会改动 `%APPDATA%\Unknow\agent`，会话与设置全部保留（旧配置会在启动时自动迁移到新格式）。
- **卸载**：从「设置 → 应用 → 已安装的应用」中找到 Unknow 卸载，或运行安装目录下的卸载程序。卸载不会自动删除数据目录，需要彻底清理时手动删除 `%APPDATA%\Unknow`。

## 八、常见问题（FAQ）

### Q1：运行时报「Windows 已保护你的电脑」怎么办？

这是 Windows SmartScreen 对未签名程序的常规拦截提示。点击 **「更多信息」** → **「仍要运行」** 即可正常启动。

### Q2：提示「网页版 AI 未就绪」怎么办？

说明该网页版 AI 站点尚未登录。请先进入 **设置 → 网页版 AI**，完成对应网站的登录，再返回使用；站点列表里没有你常用的站点，也可以自行添加。

### Q3：模型回复报错怎么办？

请先检查设置中的 **API 地址** 与 **密钥** 是否正确、是否已填写对应**模型名**，以及所填模型服务是否可用。若本机直连外网不顺，打开 **设置 → 网络出口** 再试。

### Q4：模型报 400，提示「该模型始终思考，不支持关闭思考；请使用 low、high 或 max」？

这是上游模型对**推理档位取值**的限制，不是密钥或模型名的问题：部分模型（如 GLM-5.3 系列）只接受 low / high / max，没有「关闭思考」这一档。当前版本已按模型族收敛档位（选「中」自动走 high、xhigh 走 max、minimal / none / off 走 low），并在上游仍然拒绝且尚未产出内容时自动改用 high 重试一次。若仍看到该报错，先把程序升级到最新版本再试。

### Q5：翻译为什么没有消耗 token？

划词翻译默认使用内置翻译引擎（公开翻译接口），不经过模型，因此不计费、几乎不耗时。只有你主动点「AI 翻译」，或手动开启「失败自动改用 AI」并遇到内置引擎全部失败时，才会调用模型。

### Q6：翻译提示失败怎么办？

内置引擎依赖网络：腾讯交互翻译国内可直连，Google / Bing 需要能访问外网。若全部失败，可切换引擎后重试，或直接点「AI 翻译」交由模型处理。

### Q7：划词没反应 / 取不到选中的文字？

- 应用内划词需要**先选中文字**再按快捷键，没有选区时会直接判空，不会去抢外部前台；
- 外部程序需先获得焦点并完成选中，快捷键不要在选区消失后再按；
- 以管理员权限运行的程序、部分自绘界面（如某些游戏、终端）可能取不到选区文字，可改用截屏问 AI；
- 仅 Windows 支持划词取词，其他平台会明确失败并写入日志。

### Q8：截屏是黑屏 / 截到了另一块屏？

- 默认按**鼠标所在屏幕**截取，也可在框选界面手动选择屏幕；
- 播放受版权保护的视频、部分全屏独占程序会呈现黑屏，这是系统层面的截屏保护，无法绕过；
- 若截图一直停在「截取屏幕中…」，多为屏幕捕获权限或安全软件拦截，可重启程序后重试。

### Q9：检查更新失败 / 没有提示新版本？

版本检测在启动后自动进行，网络未就绪时会自动退避重试；也可在「设置 → 关于」手动点击 **「检查更新」**。若长期失败，先确认本机可以正常出网（必要时打开「设置 → 网络出口」），再重试。

### Q10：任务一直停在运行中 / 显示「预算耗尽」？

任务由多个步骤串并行执行，单步有超时上限（默认 10 分钟），卡住时会自动标记失败并按依赖继续。遇到方向不对时，直接在详情页用**纠偏**或**改目标**介入，比等待更快；「预算耗尽」表示达到步数上限，程序会先写出已有发现的报告再结束。

### Q11：上传日志会不会带走我的对话内容？

不会。上传内容仅包含最近 3 天的运行日志与崩溃堆栈，日志中不含对话正文，且路径里的用户名会先被脱敏；是否上传完全由你决定。

### Q12：日志在哪里？

日志位于**程序数据目录**下的 `logs` 文件夹中：

```text
%APPDATA%\Unknow\agent\logs\
```
